# 数据来源与采集边界

## Steam Charts

Steam Charts用于建立研究样本。生产采集将记录榜单类型、榜单日期、排名、AppID和采集时间，并保留原始快照。

项目研究对象是“进入所选Steam榜单的热门游戏”，不能据此描述全部Steam游戏。

## Steam商店信息

可行性阶段使用Steam公开商店商品信息端点获取名称、类型、价格、开发商、发行商、类型和语言列表。

该端点不是本项目能够控制的稳定契约，因此：

- 每次响应都会先写入带日期的本地缓存。
- 关键字段必须通过模式和类型检查。
- 字段消失或含义改变时，采集任务应失败，而不是发布不完整数据。
- 简体中文的界面、字幕和音频支持范围需要在生产阶段通过商店语言表另行验证。

## Steam用户评论

评论汇总使用Steamworks文档提供的公开评论接口：

`GET https://store.steampowered.com/appreviews/<appid>?json=1`

项目分别请求：

- `language=all`
- `language=schinese`
- `purchase_type=all`
- 默认排除平台标记的题外活动

主要使用`query_summary`中的正面评论数、负面评论数和评论总数。评论语言不等同于玩家国籍。

## 隐私和再发布原则

- 不采集或发布SteamID。
- 生产仓库不提交大批完整评论原文。
- 文本分析只发布聚合主题、必要的短摘录和可复现的派生特征。
- 不把评论数、SteamSpy拥有者估计或在线人数解释为真实销量。
