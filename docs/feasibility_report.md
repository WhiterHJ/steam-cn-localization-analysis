## 数值合理性检查

- 10款游戏均有全语言和简体中文评论。
- 简体中文评论数均未超过全语言评论数。
- 所有正面评论数与负面评论数之和均等于评论总数。
- 中文评论占比范围为7.23%至50.89%。
- 中文与全语言好评率差值范围为-23.19至+3.16个百分点。

这些差异表明指标具有区分度，但不构成正式业务结论。

## 已知问题

1. 验证样本由人工选择，而且10款游戏均支持简体中文，不能用于比较“支持”和“不支持”两组。
2. 免费游戏不会返回常规价格字段，这是合理缺失值。
3. 当前商店汇总字段只能确认是否列出简体中文，尚不能稳定区分界面、字幕和完整音频。
4. 商店商品信息端点需要持续缓存和字段验证，以应对未来结构变化。
5. 排行榜采集尚未完成，正式样本量和覆盖范围仍需在下一阶段确定。
