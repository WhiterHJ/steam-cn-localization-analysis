# 首期分析报告

数据快照：2026-09-12（UTC）。

## 样本与覆盖

- 两个榜单共200个位置，合并后得到148个唯一 AppID；
- 排除2个非游戏条目后，生产样本为146款游戏，候选覆盖率98.65%；
- 129款游戏标注支持简体中文，占88.36%；
- 139款游戏至少出现1条简体中文评论，占95.21%；
- 131款游戏达到“全语言评论不少于1,000且中文评论不少于100”的稳健展示阈值。

## 关键观察

### 1. 中文评论已是热门游戏评论生态中的常见组成

在达到阈值的131款游戏中，简体中文评论占比中位数为12.34%。这不表示中国市场贡献了相同比例的销量，只表示公开评论的语言构成。

中文评论占比最高的游戏包括：

1. NARAKA: BLADEPOINT：83.39%；
2. PUBG: BATTLEGROUNDS：50.89%；
3. Slay the Spire 2：49.32%；
4. Onimusha: Way of the Sword：46.83%；
5. Wallpaper Engine：44.65%。

### 2. “参与很多”不等于“评价更好”

稳健展示样本中，简体中文好评率相对非中文好评率的中位差为−9.23个百分点。部分中文评论占比较高的游戏同时存在明显负向评价落差，说明参与度和态度是两个不同维度。

差距最大的一组包括 Slay the Spire 2、HELLDIVERS 2、Wanderburg、WARDOGS 和 Monster Hunter Wilds。该结果描述的是采集时点的累计评论汇总，不能仅凭差值判断具体原因。

### 3. 中文支持与中文评论占比存在明显关联

达到阈值的游戏中：

- 标注支持简体中文的118款游戏，中文评论占比中位数为13.02%；
- 未标注简体中文的13款游戏，中位数为2.57%；
- 中位数差为10.44个百分点，95% bootstrap 区间为5.54至13.02个百分点；
- Mann–Whitney U 双侧检验 `p = 0.000223`。

这个差异适合用于提出后续研究问题，但不是“增加中文支持会带来10.44个百分点中文评论”的因果估计。游戏类型、发行规模、地区运营与既有玩家基础都可能同时影响两个变量。

## 可传播结论

本期最值得传播的不是某一款游戏的排名，而是一个更稳健的叙事：在 Steam 热门游戏中，中文评论已经高度可见；但中文评论者的参与强度与评价体验并不总是一致。本地化是否存在，只是问题的起点，质量与社区预期才是下一阶段需要解释的部分。
