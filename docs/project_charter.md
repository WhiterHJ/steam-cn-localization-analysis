# 项目章程

## 核心问题

Steam 热门游戏的简体中文支持情况，与中文评论参与度和中文评价表现之间呈现什么关系？

## 产品定位

本项目是一个自动采集、自动分析并公开发布的专题数据产品，而不是要求访客上传文件的通用分析工具。

## 目标用户

- 希望了解热门游戏中文口碑差异的玩家
- 关注本地化机会的独立游戏开发者和发行者
- 希望核验方法和结果的数据分析从业者

## 初始分析范围

1. 从 Steam 官方排行榜建立热门游戏样本。
2. 获取游戏基本信息及简体中文支持状态。
3. 分别获取全语言和简体中文评论汇总。
4. 构建中文评论占比、中文好评率和评价差值。
5. 识别“高中文关注、无简中支持”等值得深挖的游戏。
6. 对代表性游戏的中文评论进行可解释的主题分析。

## 成功标准

- 数据采集可以缓存、重试并记录采集时间。
- 关键表具有明确主键和自动质量检查。
- 所有主要指标具有书面定义和测试。
- 网站明确显示样本边界、更新时间和研究限制。
- 公开结论可以由仓库中的处理数据和代码复现。

## 明确不做

- 不把 Steam 评论数解释为销量。
- 不把中文评论者解释为中国玩家。
- 不把相关关系写成因果关系。
- 不发布 SteamID 或大批完整评论原文。
- 第一版不构建用户上传数据的通用分析平台。
