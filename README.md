# Steam 中文评论与本地化观察站

> 项目状态：数据源可行性验证已通过，正在构建 Steam 榜单样本采集与生产数据模型。

本项目研究 Steam 热门游戏中，简体中文支持、中文评论参与度与评价表现之间的关系。

项目将从 Steam 公开排行榜、商店信息和用户评论接口采集定期快照，经过可复现的数据验证、统计分析与中文评论主题分析，生成可公开访问的交互式数据故事网站。

## 当前研究边界

- “中文评论”指评论时选择的语言，不等同于玩家国籍或所在地区。
- 评论数量用于衡量公开评论参与度，不等同于销量、玩家数或收入。
- 项目分析的是进入所选 Steam 榜单的热门游戏，不能代表全部 Steam 游戏。
- 观察性数据只能说明相关关系，不能证明增加简体中文支持会导致销量或好评率变化。

## 预期公开成果

- 自动更新的 GitHub Pages 数据故事网站
- 可复现的数据采集、清洗、统计与文本分析代码
- 数据字典、指标口径、质量报告和研究限制
- 阶段性数据快照与分析报告

## 数据源

- [Steam Charts](https://store.steampowered.com/charts/)
- [Steam 用户评论接口](https://partner.steamgames.com/doc/store/getreviews)
- Steam 商店公开页面与商品信息
